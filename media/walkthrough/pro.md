# Columns and statistics (Pro trial)

Open the JSON Lines sample, run **Choose Parse Profile** and pick "Detect from the first lines" to get columns, field filters such as `status>=500` and sorting. **Show Statistics** counts lines by level, shows the rate over time and lists error bursts.

The first Pro command starts a free 14-day trial on this computer. It needs no key, no account and no network. **Show Licence Status** shows the days left.
